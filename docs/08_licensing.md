## 1. なぜ公開コードにライセンスが必要か

GitHub にコードを置くだけでは、「どのように利用してよいか」は **明示されません**。多くの国では、著作権のある作品は原則として **著作者の許可なしに複製・改変・再配布できません**（All Rights Reserved に近い状態）。

リポジトリのルートに **`LICENSE`（または `LICENSE.md`）** を置くと、

- 他人が **合法的に利用できる範囲**
- **改変・再配布** してよいか
- **商用利用** や **特許** に関する扱い

がテキストで示されます。オープンソースを「ちゃんと使えるようにする」ための最低限の礼儀です。

**この教材リポジトリ** では、`LICENSE` ファイルを置くかどうかは **オーナー（山本）が判断** します。参加者は merge 後の README を確認してください。

## 2. よく見るソフトウェアライセンス（ざっくり）

| ライセンス | おおむねのイメージ |
|------------|-------------------|
| **MIT** | 非常にゆるい。著作表示を残せば、商用・改変・再配布がしやすい |
| **Apache-2.0** | MIT に近いが、**特許** に関する条文が明示される |
| **GPL（v2 / v3）** | 配布する改変版にも **同じ自由を渡す義務**（コピーレフト）が強い |

Julia の **General レジストリ** にあるパッケージの多くは **MIT** です。依存関係を楽にするため、パッケージ作者も MIT を選ぶことが多い、という文化があります（各パッケージの `Project.toml` やリポジトリの `LICENSE` で必ず確認してください）。

## 3. GitHub で `LICENSE` ファイルを追加する方法

1. リポジトリ → **Add file** → **Create new file**
2. ファイル名を **`LICENSE`** にすると、「Choose a license template」の案内が出ることがある
3. **MIT License** などテンプレートを選び、著作年・著作者名を編集
4. コミット（`main` 直コミットか、ブランチ + PR）

既に `main` に MIT の `LICENSE` がある場合でも、**意図を README に書く** と親切です。

---

## 4. コード以外：Creative Commons（CC）

**論文・スライド・解説 Markdown・図のキャプション** など「文章・コンテンツ」には、ソフトウェアライセンスとは別系統の **Creative Commons** がよく使われます。

- **CC BY** … 表示（クレジット）さえすれば再利用・改変が比較的自由
- **CC BY-SA** … 改変物にも同じライセンスを付ける条件（ShareAlike）
- **CC0** … できる限り権利放棄に近い宣言（データセット公開など）

**コード（MIT 等）** と **文章（CC BY 等）** を **分けて明記** するリポジトリも多いです。本教材の `docs/` や `README` を再利用するときは、merge 後にリポジトリに書かれたライセンス表記に従ってください。

---

## 5. データのライセンス

`data/` の CSV のように **データ単体** を公開する場合も、利用条件を決めます。

- 個人を特定しうる **実データ** は、ライセンス以前に **倫理審査・同意** が前提
- 架空の教材データでも、「再配布・改変可」など方針を README に書いておくと親切

---

## 6. 論文用コードを Zenodo で公開するときの注意

[Zenodo](https://zenodo.org/) で GitHub リリースと連携して **DOI** を付ける場合、次を意識することが多いです。

1. **その版のコード** に [タグ](06_tags_releases.md) を付け、リリースと内容を一致させる
2. リポジトリに **明確な LICENSE** がある（Zenodo のメタデータでもライセンスを選ぶ）
3. **第三者データ** や **非公開参加者データ** が混ざっていないか
4. DOI は **版ごと**（v1, v2…）。論文には「使った DOI / タグ」を明記する

Zenodo に送る内容と GitHub 上のライセンスが **食い違わない** よう揃えるのが基本です。

---

## 7. まとめ

- ライセンスなし公開は、実質「ほかの人は触れない」に近い
- Julia パッケージは **MIT** が多いが、依存先それぞれを確認
- **コード・文章・データ** で別ライセンスにすることがある
- 論文・Zenodo では **版（タグ）とライセンスをセット** で考える
