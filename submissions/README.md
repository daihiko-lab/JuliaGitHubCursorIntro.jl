# PR 課題: 自己紹介スクリプトを追加する

Git/GitHub ハンズオンの最後に、**自分専用の Julia ファイルを1つ追加して PR を出す**課題です。全員が **別ファイル名** にするので、PR 同士が衝突しにくくなっています。

## やること

1. `main` から **自分用のブランチ** を切る (例: `feat/intro-yamada-taro`) 
2. このフォルダに **`あなたのGitHubユーザー名.jl`** という名前で新規ファイルを作る  
 (ユーザー名にドットが含まれる場合は、そのまま使って構いません) 
3. ファイルの中身は下記「最低限の要件」を満たすこと
4. コミットして push し、**ハンズオン用リポジトリ** (オーナー案内の Private コピー) へ **Pull Request** を作成する
5. PR が作られると **CI が自動実行** されます。緑になれば合格ラインです (詳細は [docs/05_ci.md](../docs/05_ci.md)) 

## 最低限の要件

- ファイルを `include` したときに **エラーで止まらない** こと
- コンソールに **あなたの表示名 (ニックネーム可)** と **一言メッセージ** を `println` すること
- (任意) このゼミで学びたいこと・意気込みを1行足してもよい

## 見本

動作の参考として、次の見本ファイルがあります (PR 課題として提出する必要はありません) 。

- [`example_githubuser.jl`](example_githubuser.jl)

## 自分用ファイルのひな形

```julia
# 参加者: あなたのGitHubユーザー名

function introduce()
    println("表示名: 山田 太郎")
    println("一言: Julia と Git をこれから一緒に学びます。")
end

introduce()
```

## 注意

- **他人のファイルは編集しない**でください (自分の `.jl` だけ追加・変更) 
- 図やメモを PR に載せたい場合は、**このフォルダ内** に置くか、リポジトリの他の場所ではなく **自分のファイル名の近く** にまとめてください
- 機密情報 (本名のフルネーム・連絡先など) は **書かない** ことを推奨します
