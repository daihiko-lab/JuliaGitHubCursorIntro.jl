# 参加者一覧 (PR 課題ステップ 4 用)

このファイルは **全員が同じファイルを編集** するため、先にマージされた PR があると、あとから出す PR で **コンフリクト** が起きやすくなっています (意図した体験です) 。

## ルール

- **表の末尾に1行だけ** 自分の情報を追加する (既存の行や見出しは触らない) 
- 平均の計算結果は、自分の `submissions/<GitHubユーザー名>.jl` で定義した `my_mean` を使い、例として `[1, 2, 3, 4, 5]` など好きな配列で計算した値を書く (全員同じ配列でなくてよい) 
- マージの順番は自由だが、**コンフリクト解消** の練習はオーナー・TA の指示に従う
